## The branch's behavior kept

- Transcript: no per-token whole-transcript rebuild. Chunks still coalesce per frame (`AgentChatStore.receive`/`flushChunks`), and the copy-free in-place append is kept with upstream's `startsNewAttempt`. The new row inputs (`earlierHistory`, `retryPending`) are in `ChatTurnContext`, so only the first or last turn rebuilds when they change. Find in Chat reads row frames from the layout (O(log n)) instead of per-row geometry callbacks; only the row holding the current match is redrawn. `SmoothChatTests` passes.
- Workspaces: `WorkspacesCollection` + `WorkspacesListMenus` (menus built when they open). Upstream's new rows were added there, not to a per-row SwiftUI `.contextMenu`.
- Diff: `DiffCodeList` stays O(visible rows). Search paints only the configured cells. Matches and hunk starts are memoized per (file, options, query).
- Tabs: stored tabs and same-turn staleness (`flushStale`); `workspaceTab` reads the listed entry.
- Feed: index by id and batched read marks. `TerminalFeed`: linear echo set.
- `WorkspaceSync`: the repeated-title fix (see the #27299 row).

## Not ported exactly

None. One change is equivalent but not the same code. Upstream's `DiffFileScreen.anchorLine(for:)` (the row of a split pair) is `DiffRenderModel.rowByLine` here, because there are no SwiftUI row ids in the collection view. The scroll anchor is upstream's 25% point.
