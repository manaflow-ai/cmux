# マウス

[English](mouse.md)

## クリック対象

ファイルサイドバービュー（`sidebar.view = "files"`）には、フォーカス中のペインの cwd、ディレクトリまたはファイルの行、件数またはフィルターのフッターが表示されます。行を 1 回クリックするとファイル行を選択します。Crossterm のマウスイベントには既存のダブルクリックという概念がないため、クリックでは開いたり移動したりしません。サイドバーにフォーカスがある状態で `Enter` または `Right` を使います。フォーカス中のサイドバーで `Tab` を押すか `toggle-sidebar-view` アクションを使うとワークスペース表示に切り替わります。

ワークスペース表示には、見出し行なしで各ワークスペース 2 行と `+ new workspace` が表示されます。ワークスペースレールにキーボードフォーカスがあると、ワークスペース行にカーソルを合わせたとき、そのワークスペースをペイン領域にプレビューし、フォーカスを確定せずに選択を更新します。`Enter` はプレビューを確定してペインへフォーカスを移します。Esc はプレビューをキャンセルし、直前のワークスペースとペインのフォーカスを復元します。右側のペインをクリックするとプレビューを確定し、クリックしたペインにフォーカスします。ワークスペースのどちらの行をクリックしても選択できます。`+ new workspace` をクリックすると作成します。ワークスペース行が表示領域を超えた場合だけ、ターミナル風スクロールバーがリサイズ仕切りの 1 列内側に表示されます。レール上でホイールを回すか、スクロールバーの透明なトラックをクリックするか、つまみをドラッグして一覧をスクロールします。組み込みビューのサイドバー右端をドラッグすると、その TUI セッションだけの幅を設定できます。`sidebar.max_width` が 0 より大きい場合はドラッグ幅を制限し、TUI はペイン用に少なくとも 40 列を残します。

各ペインには境界ボックスがあります。ペイン内をクリックするとフォーカスします。上端の境界はタブバーです。タブチップをクリックして選択し、`+` をクリックして PTY タブを作成し、`‹` または `›` をクリックしてタブチップをスクロールします。バー上でホイールを回すと、アクティブなタブを表示したままチップをスクロールします。
