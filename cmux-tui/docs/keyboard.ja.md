## フォーカス中のサイドバー

組み込みサイドバーにフォーカスがあると、仕切りが強調色のレールになります。`Tab` はサイドバーのフォーカスを保ったままファイル表示とワークスペース表示を切り替えます。ファイル表示では、上下矢印または `Ctrl-J` / `Ctrl-K` で選択を移動し、`Right` でディレクトリに入り、`Enter` でディレクトリに入るかファイルを新しい `$EDITOR` タブで開きます。`Left` または `h` は、マシンレールがない場合に親へ移動します。`c` はフォーカス中のペインへ安全に引用した `cd` を送り、`o` は `.html` と `.md` のファイルをブラウザタブで開きます。`.` はドットファイルを切り替え、`/` はフィルターモードに入り、`~` はフォーカス中のペインの cwd を再び追跡します。Esc は、フィルターモードを終了する前に空でないフィルターを消去します。

ワークスペース表示では、上下矢印または `j` / `k` で選択を移動し、クライアントのフォーカスを変更せずにそのワークスペースをペイン領域へプレビューします。`Enter` はプレビューを確定してワークスペースへフォーカスを移します。Esc はプレビューをキャンセルし、ナビゲーション前にアクティブだったワークスペースとペインのフォーカスを復元します。1 階層の `tabs` ビューは、強調表示されたワークスペースに追従します。`workspaces → agents` のような多階層ビューは折りたたみ可能なツリーです。`Left` で折りたたみ、`Right` で展開し、Space で切り替え、`Enter` で正確なワークスペース、ペイン、タブ、またはエージェントサーフェスを有効にします。矢印または `hjkl` と Alt/Option を組み合わせると常にナビゲーションになり、Alt-Left と Alt-Right はツリーの展開を変更せずにビューを移動します。最後のビューからの `Right` または Esc はペインへ戻ります。通常のプレフィックス付きコマンドはサイドバーのフォーカスを離れ、通常のアクション表で実行されます。設定されたサイドバープラグインは、既存の PTY 転送動作を維持します。

オプションのマシンレールが表示されている場合、`Ctrl-b S` はワークスペースを含む最初のビューから入ります。Alt/Option-Left または Alt/Option-`h` をペイン境界の左端で押すと、右端の表示ビューへ入ります。`Left` または `h` と `Right` または `l` は、ネイティブビューの順序を移動します。上下矢印または `k` / `j` は選択したマシンを変更し、`Enter` は接続し、プロバイダーがスコープやアクションを提供する場合は `m` がメニューを開き、Esc はアクティブなペインへ戻ります。ビュー上部の 1 行パッドをクリックすると行を有効にせずフォーカスします。マシン、ワークスペース、ペイン、タブ、エージェントをクリックするとそれを有効にし、キーボード入力を最後に使ったターミナルへ戻します。サイドバービューは、その他のプレフィックスなしキーをリモートターミナルへ転送せずに処理します。
