Contours: point of view, a map of a place that is thinking. Topographic contour lines over a height field that changes shape slowly instead of sliding: a 4-octave fbm of 3D value noise whose third axis is time (0.011 units/s at speed 1, each finer octave 1.6x, 2.2x, 2.8x faster), every octave rotated 37 degrees and scaled 2.03 so the value grid never lines up. One field unit is 300 points.
Lines: the noise returns its analytic gradient (Quilez's value noise with derivatives, carried back through each octave's matrix), so every contour is drawn at a constant width in pixels (distance to the nearest level / gradient length, then a 1 px box filter; a line thinner than a pixel fades instead of breaking up). No dpdx/dpdy, so there is no 2x2 quad coarseness and no uniformity constraint. Every 5th contour is an index line, 1.9x wider and 1.6x stronger. Minor lines fade out where adjacent ones would come closer than 3 to 7 px, index lines where theirs come closer than 2 to 4.5 px (cartographic generalisation): steep ground never turns into moire.
Paper: the theme's paper in OKLab, tinted toward the accent's hue turned by `hue` degrees (`tint`, up to 0.05 chroma), with a hypsometric shift (L and a little chroma by height) and a faint hillshade lit from the upper left, both scaled by `contrast`; a static paper tooth (no time term, so no shimmer). Final color has a static triangular +-1 LSB dither in the encoded space, so the tint never bands.
Motion: contour lines move only where the field changes; at speed 1 that is a few points a second at most and mostly much less: felt, not watched. The pointer raises a Gaussian hill (radius 150 points, height 0.45 x `hill`) eased with presence, so contours gather around it in rings and relax when it leaves.
Light and dark: all mixing is in OKLab, so ink-on-paper and light-on-dark read at the same contrast with no per-theme factor. Night Chart is dark-only (cyan lines, paper tinted toward navy by turning the cyan hue 60 degrees).
Still: time 40 s, pointer at (0.62, 0.44): a complete map with a hill under the pointer.
Cost per pixel: fbm 4 octaves x (8 hashes ~80 ALU + interpolation and derivatives ~45 + matrix ~10) ~540 ALU; hill 1 exp ~15; contours ~25; color (3 OKLab conversions of the theme colors, hue turn, back to RGB, dither) ~150 ALU with ~25 transcendentals: ~730 ALU per pixel, no loops past 4, no textures.
Budget: scale 0.5 (a 1440 x 900 point window on a 2x screen is 1.3 M pixels) at 15 fps: ~0.95 G ops a frame, estimated ~0.4 ms on an M1-class GPU; not measured on a Mac yet. Scale 0.5 is chosen over 0.75 for the budget: at 0.5 on a 2x screen one rendered pixel is one point, the 0.8 point default line is a clean 1 px AA line, and its bilinear upscale reads as a soft pencil line, which suits a map.
Params (8): levels (contours per unit of height), line (points), contrast, speed, hill, accent (line toward accent), tint, hue (tint hue turn, degrees).
