The rows of the test-hooks check (src/test_hooks.rs), read by test_hooks_tests.rs.

Kept out of the .rs sources so no checker reads a row's source as the crate's own statics. Each row
starts with a line `=== KIND ARGS :: TITLE`; its source runs to the next `===` line. KIND is
  passes FILE                   the check finds nothing in FILE (a path under src/)
  refused FILE LINE [WORDS]     the check names FILE:LINE, with WORDS in that finding, and
                                nothing else; `& LINE [WORDS]` names one more finding (each named
                                finding takes one, so a second copy of one fails the row)
  clear FILE LINE               the check names nothing at FILE:LINE
  chain refused|passes          a generated chain (the property's prelude goes first): the python
                                check's verdict, which this check gives too
The rows of check-test-hooks.test.sh come first, then the review rows (#41427, #41383, the
type-alias rows of the timing-ratio review, and #41523), then the chains.
