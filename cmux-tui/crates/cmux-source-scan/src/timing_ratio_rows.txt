The rows of the timing-ratio check (src/timing_ratio.rs), read by timing_ratio_tests.rs.

Kept out of the .rs sources so no checker reads a row's `#[test]` as a test of this crate. Each row
builds a cmux-shaped checkout: crate `demo` under cmux-tui/crates, its integration test binary
`timing` (tests/timing.rs), and, when the row has one, cmux-tui/.config/nextest.toml. It then scans
the checkout as `cmux-source-scan timing-ratio CHECKOUT` does.

A row starts with `=== VERDICT :: WHAT :: KIND :: TITLE`:
  flagged  a finding's line holds WHAT (the comparison) and, unless KIND is `-`, KIND;
  clean    no finding at all (and none names WHAT);
  tests    the tests with a finding are exactly WHAT (comma-separated names, `-` for none).
`--- rust` (the default) starts tests/timing.rs, which gets PRELUDE in front: `use std::time::{Duration,
Instant};` and `fn helper() -> Duration`, which reads the clock. `--- bare` starts tests/timing.rs
without PRELUDE, `--- nextest` the nextest.toml.

Sources: the rows of cmuxterm-hq's tools/agent-guards/test_rust_timing_ratio.py (hq#9512, its review
findings F1-F4 and the self-test of tools/rust-timing-ratio/check.py), the review of hq#9478 (F1
percentile spellings, F2 braces in strings, F3 #[ignore] before #[test]), the tokio rows, and the review of #41523 (F3 `start_paused = false`).

=== flagged :: busy < idle * 4 :: ratio of two timings :: cmux#41346's own shape: a closure returning a percentile field, called for each side (missed by hq#9512)
struct Round { p99: Duration }

fn notices_round(busy: bool, round: usize) -> Round {
    let started = Instant::now();
    let _ = (busy, round);
    Round { p99: started.elapsed() }
}

#[test]
fn a_reader_walking_every_row_never_holds_up_a_peer_notice() {
    let p99 = |busy: bool, round: usize| {
        notices_round(busy, round).p99.min(notices_round(busy, round + 1).p99)
    };
    let busy = p99(true, 1);
    let idle = p99(false, 3);
    assert!(busy < idle * 4, "a busy reader held notices up: p99 {busy:?} against {idle:?} idle");
}
