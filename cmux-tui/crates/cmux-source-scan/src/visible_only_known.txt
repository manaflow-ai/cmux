# check's start (2026-11-18). `PATH FN walks=W clones=C :: why`, PATH from the checkout.
#
# The list only shrinks: `cmux-source-scan visible-only CHECKOUT` fails when a fn has more hits
# than its row (a new walk or clone) and when it has fewer (lower the row, or take it out). A fn
# not listed has none allowed. Before adding a row: bound the loop to the viewport (skip/take
# over the visible range), or keep the model between frames (acpmux-tui src/render/cache.rs);
# a row says why the collection stays small.
#
# Rows marked REAL grow with sessions, items or tabs: the fixing lanes own them.
