USAGE: cmux link <init|show|peer|serve|ensure|stop|status|dial|install-agent|uninstall-agent> [OPTIONS]

The link owns this machine's overlay endpoint: one WireGuard key and one UDP
port for every paired machine. Same network only: no relay yet.

  init --install ID [--port PORT]   create the key and config (port 4101)
  show                              print the public key, overlay address and state
  peer add --install ID --user ID --team ID --public-key BASE64 [--endpoint IP:PORT]
  peer remove --install ID
  peer list
  serve [--session-socket PATH]     run the link; with a session socket, paired
                                    peers reach that daemon's remote entry only
        [--server-config PATH]      server.json with an owner_session block (default
                                    ~/.config/cmux/server.json): the server's owner, and
                                    only the owner, also reaches the Chief brain's daemon
  ensure [--install ID] [--port PORT] [--session-socket PATH] [--server-config PATH]
                                    start `serve` in its own session unless one runs for this
                                    state directory (init first when there is none; --port 0
                                    binds any free port); one JSON line with status
                                    running|started|restarted
  stop                              stop the link of this state directory (its registered pid)
  status                            print whether the link runs, and its pid, socket and build
  archive                           after a sign-out: keep the install's key and peers under
                                    its name and remove the config (the link must be stopped)
  dial --host ID [--service daemon|ssh|owner_session] [--socket ABSOLUTE_PATH]
                                    bridge stdin and stdout to a paired install or Cloud
                                    host; one JSON line on stderr, exit 0 ok, 2 unknown host,
                                    3 not authorized, 4 paused, 5 unreachable, 6 no link,
                                    64 bad usage
  install-agent [--session-socket PATH]   run `serve` as a launchd agent (macOS)
  uninstall-agent

Every action takes --state-dir DIR (default: <daemon state dir>/link).
