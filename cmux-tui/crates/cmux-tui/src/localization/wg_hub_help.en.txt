USAGE: cmux wg hub --config PATH --socket PATH [--control PATH] [--probes] [--send-buffer BYTES]

Own one in-process WireGuard tunnel and serve SOCKS5 CONNECT for other cmux
processes on an owner-only Unix socket. A WireGuard key supports one live
session, so every `remote connect --wireguard-hub PATH` sidecar on this machine
shares this hub instead of handshaking on its own.

  --config PATH   owner-only wg-quick file (PrivateKey, Address, AllowedIPs, Endpoint)
  --socket PATH   Unix socket to serve; parent directory is created 0700, socket 0600
  --control PATH  also serve a control socket (newline-delimited JSON): `path.get`,
                  `path.subscribe` (`path.changed` events), `datagram.bind` (an overlay
                  UDP port on a Unix datagram socket in PATH.d/, with a priority
                  class: interactive, media or bulk) and `datagram.stats`
  --probes        measure the path with probes; only for a peer that answers them
  --send-buffer BYTES  UDP send buffer, 16384 (the default) to 4194304; a small one
                       keeps queues in the hub, where media overtakes bulk
                       (raised to fit one full datagram of the MTU; Linux limits
                       it to net.core.wmem_max)

Prints one JSON line `{"event":"hub-ready","socket":...,"routes":[...]}` when
listening (it also names `"control"` with --control). Only literal IP targets
inside AllowedIPs are dialed; other targets get SOCKS reply 0x02, names 0x08.
Exits on SIGTERM or SIGINT and removes its sockets.
