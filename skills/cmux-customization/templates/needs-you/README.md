# Needs you

See the agent chats waiting for your answer.  
The inbox updates as agents ask questions; click one to open its chat.

Copy `cmux-app.json` and `main.js` together into a new folder, then run `cmux ext dev` there. Accept the preview’s install card once; every subsequent save reloads the view.

Enable `actions:run` in Settings → Apps → Needs you for clicks.

Edit the title, filter or row text in `main.js` to make it yours. `cmux ext shot --json` captures the installed view. To remove it, run `cmux ext remove local/showcase-needs-you`.
