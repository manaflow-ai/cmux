# Tarballs for the git dependencies that Zig packages pin in their own build.zig.zon.
# scripts/ci/seed-zig-package-archives.sh seeds each one into Zig's cache as
# p/<hash>.tar.gz, so no build fetches it from its git host, and fails the fetch
# (exit 3, naming it) for a git pin that has no line here.
#
# Format: <package hash from the build.zig.zon> <tarball url of that commit>
# Zig checks the package hash of what it unpacks, so a wrong tarball fails the
# build; it can never bring in other bytes. Check a new line with
# `zig fetch <tarball url>`: it must print the hash.
#
# translate_c (ghostty-next pkg/translate-c, translate_c-02ff0c52) pins aro at
# git+https://codeberg.org/ziglang/arocc#d0c8c4d9c55daa7ef6e40cf0f630a5b5e900989b.
# codeberg.org was down on 2026-11-11 (ProtocolError in every ghostty-vt-sys build).
# `zig fetch` of this tarball prints the pinned hash (checked 2026-11-11).
