# Check paths: the files that decide what a pull request's checks enforce, not what they check.
#
# A pull request's CI judges it against the base it ran on. When one of these changes on
# feat-cmux-next after that base, the result is stale even though no file of the pull request
# changed: on 2026-10-21 #22967, #22975 and #23094 merged after #23365 landed
# webviews/scripts/check-fixed-waits.ts, without ever running it, and turned check:fixed-waits red
# on the base. A merger (next-autoland, gh-merge-green) reads this file from the base it merges
# into and, when any changed file since the pull request's `cmux-next/fast-gates` base matches a
# line here, dispatches cmux-next-fast-gates.yml for the pull request (the cheap gates and the
# webviews checks on the pull request merged with the current tip) and merges only on a
# success at a fresh base.
#
# One pattern a line, matched against the repository path with Python's fnmatch (a `*` also
# matches `/`). Blank lines and lines starting with `#` are ignored. tests/test_check_paths.py
# keeps every pattern matching at least one tracked file.
