# The Xcode each macOS runner pool builds with, keyed by the runner's macOS
# major version (`sw_vers -productVersion`).
#
# scripts/select-ci-xcode.sh reads this file when a job does not pin an Xcode
# itself, so a job selects by the pool it actually landed on rather than by the
# lane it was routed through. Every version here must be at or above the major
# named in .xcode-version; tests/test_ci_macos_xcode_selection.py enforces that.
#
# Every fleet Mac (macOS 26.6 and later, and macOS 27) builds with one Xcode:
# 27.2 (27B52) at /Applications/Xcode_27.2.app. Leo, 2026-11-26: "i've started
# thinking we want to have xcode 27.2 across the fleet standardized, no more old
# versions." One pin keeps one DerivedData and CAS key space and one set of
# runner labels (xcode-27.2). cmuxterm-hq build-fleet/mini-ops/ops/
# install-xcode-27.2.sh installs it; `xcode_pin_audit.py --exact` reports a
# host that still carries any other Xcode. Xcode 27 needs macOS 26.6 or later.
#
# macOS 15 is only the Blacksmith hosted image (no fleet Mac runs it), whose
# newest Xcode is 26.3; that line stays until those jobs move to macOS 26.
#
# macOS  Xcode
15       26.3
