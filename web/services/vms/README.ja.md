# VM プリミティブの追加契約

この文書は PR #11609 で追加した機能の日本語リファレンスです。
既存のバックエンド運用手順は [README.md](README.md) を参照してください。

## プロバイダーの機能契約

一覧、状態、作成、復元、複製、Base の各 API 応答は `capabilities` を返します。
キーは `snapshot`、`restore`、`fork`、`exec`、`stats`、`ports`、`desktop`、
`sizing`、`persistentHome`、`attachTransports` です。任意メソッドの有無から
機能を判定し、プロバイダーが宣言した値を優先します。構造から判定できない
機能は明示的に有効にしない限り無効です。クライアントはプロバイダー名ではなく、
この契約に従って操作を選びます。

`POST /api/vm` は、対応していない `memoryMb`、`persistentHome`、
`perMachineHome` を黙って無視せず、ロケールに応じたエラーを返します。
ゲートウェイで利用できない操作は `VmOperationUnsupportedError` となり、
再試行で解決しない 501 応答に変換されます。`MockVMProvider` は宣言する
接続機能に対応するメソッドを実装し、メモリ上のマシン状態を検証します。

## ポートと認証の境界

`openPort` は所有者の WireGuard トンネル経由で到達するプライベート
アドレスを返します。公開 URL や新しい TLS ルールは作成しません。
`revokeEndpointLeases` は古いプレビュー用ルールのみを削除します。
別途公開したサービスの権限や削除は、その公開機能が管理します。
ネットワーク権限の取り消しは、ブラウザーに保存済みの内容の消去を保証しません。

モデルプレーンの認証情報はエッジが保持します。ゲストの環境にはプレースホルダー
のみを書き、リクエスト時に認証ヘッダーとマシン ID を付与します。
ルールの設定に失敗した場合は、認証情報をゲストに渡す方法へ戻らず失敗させます。

## マシン内の CLI

ドライバーは作成時と接続の修復時に `/usr/local/bin/cmux` を原子的に更新します。
デーモンが正常でも CLI の更新を省略せず、インストールの失敗を呼び出し元へ返します。
ローカル操作はマシン自身のセッションを使用します。接続先への操作には
`~/.cmux/peers/<dst>.json` にある既存の許可が必要です。

現在の main は信頼済みプライベート接続へ移行しており、このブランチには古い
Mac の `vm link` 登録処理はありません。新規の接続許可の作成は未提供であり、
検証済みの機能として案内しないでください。アカウントの認証情報はゲストに渡しません。

接続完了はプライベート FIFO 上のデーモンイベントで通知されます。Bash の
ブロッキング `read -t` により 30 秒の期限を設け、キャンセル時には開始した
プロセスを終了します。出力ファイルの繰り返し走査や待機用の `sleep` は使いません。
ゲストの案内文は両方の web メッセージカタログの `guestCLI` にあり、
`LC_ALL`、`LC_MESSAGES`、`LANG` の順に英語または日本語を選びます。
