# A chat view's fields and their homes with `chat` on

With the `chat` stream on, the daemon sends a window of rendered rows and four ops (`row`, `text`, `patch`, `queue`). The page keeps its v1 connection for what is not the chat's rows. This file names one home for every field the pane reads. Per decision 229, "no source" is not a home; a field the wire lacks yet is listed under "Not yet" with the row that builds it.

The seven homes (decision 229):

- **a**: the row itself, head or body. The translator writes it at append.
- **b**: the turn's group row. Anything about a turn as a whole, or about rows of the turn that a window may not hold.
- **c**: the open rows. The store holds all of them (at most 64), so a function of them is allowed.
- **d**: the window's state: cursor, hasBefore, hasAfter, the queue head, the seen row, open folds.
- **e**: the list summary.
- **f**: the v1 connection's requests and a watcher's notifications (`_acpmux/session_changed`, `_acpmux/permission_pending`, `prompt_accepted`).
- **g**: the page's own state (an optimistic send, what is expanded, the clock).

A page-made field is allowed only when it is a pure function of one row's own fields, of the open rows, or of homes d to g. A function of other settled rows is home b; if the group row lacks what it needs, the field is a gap.

Builders: **built** (on the wire now), **2c** (the translator, decision 231), **2d** (the queue, decision 232), **A0**, **row 11** (only an answer's send).
