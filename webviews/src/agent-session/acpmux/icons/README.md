# icons

The agent pane's side of the cmux icon registry: `<Icon name="…" />` draws an icon from the active
pack in the text color, Solid when `selected`, with Cat-accent layers in `--agent-accent`.
`IconsProvider` supplies the pack and accent (the bundled pack and no accent by default), and
`rowIconSize` sizes a row icon from its label.

`cmuxIcons.json` is generated by `scripts/icons/build_pack.py` from the authored SVGs in
`design/icons/source/`. Do not edit it by hand; rerun the script (`--check` verifies it is current).
Native draws the same pack through `CmuxNextIcons`.

Nothing imports this module yet. Call sites migrate one surface at a time, each in its own change.
