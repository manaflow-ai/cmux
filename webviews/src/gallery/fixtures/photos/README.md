# Gallery photo backgrounds

The `photo-light`, `photo-dark` and `photo-busy` backgrounds (env.ts `BACKGROUNDS`, frame/background.ts):
real photographs to judge glass over, as people set a photo behind the window. Each is downscaled
to 1280 px wide from the Wikimedia Commons original; all are public domain or CC0, so no attribution is
required. They are credited here anyway.
