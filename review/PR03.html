PR03 — Authoritative SSH cancellation and sidebar lifecycle

Local proposal artifact · Draft for review · No branch, commit, or public PR

Outcome: Ctrl-C and terminal end reconcile the exact active generation. A never-ready workspace stops showing connecting, an established persistent PTY remains reattachable, and stale callbacks cannot mutate a replacement.

Problem and evidence

  • cmux_ssh_retire_for_signal currently invokes lifecycle-only cleanup, sets CMUX_SSH_SESSION_ENDED=1, disables EXIT cleanup, and exits.
  • Before broker registration, controlWorkspaceRemoteTerminalSessionEnd finds no broker owner and skips the presentation end even when terminal lifecycle is current.
  • workspace.remote.pty_attach_end carries only workspace/surface/session; the stable session ID is reused across retries, moves, and terminal generations.
  • The outer controller-availability loop is distinct from coordinator pendingPTYBridgeStarts; waking it without a tombstone can allow a canceled request to attach to a later controller.
  • A late valid launching callback maps an earlier controller error back to connecting.

Exact identity and wire contract

Carry these six values through terminal_session_launching, bridge request, attach end, and terminal end:

  1. workspace ID
  2. surface/attachment ID
  3. terminal lifecycle ID
  4. launch attempt ID
  5. persistent PTY session ID
  6. PTY lifecycle ID

pty_attach_end also carries end_disposition. Only literal confirmed_absent proves the remote PTY is gone and permits clearing its session mapping. Generic local detach/failure does not.

Production change contract

  1. Record all six IDs on launch. Require current identity for every Workspace/Dock mutation. Mismatch at any supplied generation is a no-op; do not add compatibility aliases that fall back to session ID alone.
  2. Generated HUP/INT/QUIT/TERM reports signal and exact identity; app state decides from an everReady latch. Pre-ready current generation enters full cancellation. Established HUP/TERM or Ctrl-C during reconnect/backoff retires only that attachment and preserves the PTY. Post-ready raw Ctrl-C remains PTY input.
  3. Authorize pre-ready presentation end from current TerminalSurface.terminalLifecycleId plus attempt even if broker owner is not registered. Claim/retire broker lifecycle separately if it exists; non-current claim remains no-op.
  4. On exact pre-ready end: write an attempt tombstone, wake both controller-availability and coordinator waiters, synchronously invalidate the matching controller ID, then stop only that transport-scoped controller. Both paths return pty_lifecycle_closed; a later controller cannot revive the request.
  5. Add everReady and typed end disposition to shared remote terminal state. Preserve the same panel across cancellation/child exit using the existing persistent-ended/replacement markers consumed by TabManager.shouldKeepPersistentRemoteSurfaceOpenAfterChildExit.
  6. Launching updates per-surface attempt but cannot demote authoritative controller .error/.suspended. Fatal outcome rejects later launch for that attempt; typed retryable outcome may present connecting.

Required state table

Prior/eventCommitted result
Initial retry before first readyPanel retained; active + launching; everReady=false; no end mutation between retries.
Pre-ready cancel/fatalPanel/config retained; active false; no waiter/controller/launching; exact disconnected/error. Session ID retained unless absence is proven.
Established detach/retryeverReady=true; retain session ID, broker/replacement ownership, controller, and reattachable panel.
Current confirmed_absentClear session mapping; set persistent-ended marker; active false; retain panel.
Stale generationNo-op.

Affected files

  • CLI/CMUXCLI+SSHStartupScripts.swift, CLI/cmux.swift, CLI/CMUXCLI+SSHPTYAttachBridge.swift: complete identity and signal/end payloads.
  • Sources/TerminalController.swift, TerminalController+ControlWorkspaceContext.swift: tombstone both wait layers and pre-broker authorization.
  • Workspace+RemoteTerminalLiveness.swift, Workspace.swift: everReady, end disposition, state precedence.
  • TabManager.swift and Dock ownership paths: persistent panel retention and moved-surface safety.

Behavior coverage

  • Signal × phase matrix: auth, controller wait, queued bridge, initial backoff, attached, established reconnect; initial and restored wrappers.
  • Cancel before controller install, then install replacement: old RPC closes, no bridge starts, both waiter registries empty.
  • Pre-broker full end commits once; late ready/connected cannot revive.
  • Old attach-end after same-session replacement and moved Dock is no-op; exact current confirmed_absent clears mapping but retains panel.
  • Child exit after pre-ready cancel, manual retry, established detach, deep sleep, move, and confirmed exit preserves the same panel where specified.
  • Ordered error → launching → end retains exact error/detail; retryable outcome may reconnect.

Review blockers

  1. Every end mutation has all six IDs; session-only cleanup is removed.
  2. Pre-broker cancellation is authorized without weakening stale-generation checks.
  3. Both readiness queues are tombstoned, not merely notified.
  4. everReady distinguishes initial cancellation from established detach.
  5. Persistent child exit retains the panel; late launching never erases fatal state.

Dependency: consume PR02's typed readiness outcome and attempt generation. No sidebar-view special case.
