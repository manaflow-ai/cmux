The Fix chip: a failed command offers a way to the agent

When a command in a terminal pane exits non-zero (read from shell integration), a small chip appears. Clicking Fix sends the command, exit code, output tail and cwd into the workspace's agent chat, or a new one. Each card is a terminal where cargo test -p cmux-git just failed, on a glass pane over a gradient backdrop. The pane keeps its one material; nothing gets an opaque backing. A lasting state the person must act on uses the small raised label.

Four placements

A. Corner chip (recommended)
zsh
~/Projects/cmux % cargo test -p cmux-git
error[E0599]: no method `fetch_tail`
 --> src/diff.rs:88:14
test result: FAILED. 41 passed; 1 failed
error: test failed, exit code 101
~/Projects/cmux %
Exit 101Fix×
Raised label at the pane's bottom-trailing corner, clear of the scrollbar, same material as "Sized for". Fades in over the glass and never moves text.

A small red dot in the left gutter beside the failed command, with "Fix" on hover. Quiet and anchored to the right line, but hidden until hovered, and it needs row geometry that shifts on scroll.

A full-width thin strip under the terminal: "cargo test failed (exit 101) · Fix · Ask agent". It pushes the terminal up, which is a layout jump, and it reads as a second toolbar.

With a range of output selected, the chip offers "Ask agent" for that selection instead of Fix.

Pick: A. The prompt that just appeared is almost always at the bottom of the pane, so the corner is next to it. It reuses the existing "Sized for" chip's material, and it needs no row geometry that changes as the terminal scrolls. B follows the prompt row, C hides until hovered, and D shifts the terminal.
