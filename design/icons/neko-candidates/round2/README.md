# Neko round 2: unaccepted line experiments

Nine original SVG experiments, Copy / Retry / Speak across three directions. All use a 24-unit grid, monochrome currentColor, 1.5 rounded stroke and a 16 CSS px intrinsic size.

- **Ear fold:** a small angular cue replaces a section of each silhouette.
- **Tail terminal:** an existing contour ends in one small curl.
- **Whisker edge:** short rays share an exposed edge or replace sound waves.

These are experiments, not accepted artwork. They deliberately leave spinner/status/security glyphs out. The whisker direction has the highest small-size recognition risk. Do not infer visual quality from file validity: compare actual 16px captures at device scale 1 and 2 in both themes against the unchanged row.

`manifest.json` records exact registry sources, per-icon modifications and the known gap between registry Copy and the current transcript Copy geometry. These gallery-only files are not imported by the production icon map.
