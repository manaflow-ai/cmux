[P2] [P2] Do not silently skip wildcard cleanup for incompatible tags
Packages/iOS/CmuxMobileShell/Sources/CmuxMobileShell/MobileMacCompatiblePairedMacStore.swift:242
A tag-less Forget deliberately enumerates every stored tag because the broker wildcard has revoked every binding for the device. However, `loadAllInstances` forwards incompatible rows while this guard turns their exact deletion into a successful no-op. `BackingUpPairedMacStore.removeExactScopes` consequently flushes the tombstone and the composite clears the marker and reports success even though the local row remains. A legacy or contaminated differently-tagged row can later resurface with an already-revoked binding. Provide a narrowly scoped deletion path that bypasses compatibility for captured wildcard cleanup, or fail the cleanup instead of silently succeeding.

[P2] [P2] Clear hidden markers in every deleted row's team scope
Packages/iOS/CmuxMobileShell/Sources/CmuxMobileShell/MobileShellComposite+HiddenMacs.swift:305
Every marker is cleared using the original display scope, although hidden markers are stored per `(user, team)`. If the same pairing was hidden in teams A and B, forgetting it from A deletes both rows but removes only A's marker (and the user-wide marker); B's marker remains. If the online Mac re-registers in B before rowless-marker migration runs, it stays unexpectedly hidden, contradicting the confirmation that it will reappear on reconnect. Clear each deleted row's marker using its captured team scope.
