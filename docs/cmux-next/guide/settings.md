# Settings reference

Every setting, its key, and its default.

Open Settings with Cmd+, or edit ~/.config/cmux/cmux-next.json. The key below is the path in that file: dots go one level down.

```json
{
  "history": { "commandRetentionDays": 30 }
}
```

This page is generated from the settings schema, so it matches the app.

The full table is generated from the app's own catalog. In a cmux terminal, `cmux settings get` print it.
