# Browser

Browser tabs, profiles, and automation.

Browser tabs open inside a pane. A tab can use Chromium or WebKit.

```bash
cmux tab new-browser
cmux browser open-in-chromium
cmux browser open-in-webkit
cmux browser screenshot-page
cmux browser import-cookies
```

## Profiles

Browser profiles keep cookies and sign-ins apart. Manage them with the cmux browser-profile commands.

## Automation

Agents drive browser tabs through the cmux CLI and MCP tools. See the CLI and MCP reference for the full list of browser verbs.
