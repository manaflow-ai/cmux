# IROH v2 client integration map

Inspected base: `72ce5e9b41a83d3f8f3a21288856449f3580686e` in `feat-iroh-v2-generation`, 10 September 2026. Links below pin that base because active implementation edits will move line numbers. This is a source map and replacement plan, not a claim of v2 completion. Requirements and proof are in [ACCEPTANCE.md](ACCEPTANCE.md).

## Entry points and active transport

The base has both `CmuxIrxTransport` and the older `CmuxIrohTransport`. IRX is selected by default in executable logic on both platforms, despite stale comments describing it as default-off. An explicit `cmux.irx.enabled=false` selects the old stack. IRX still adopts old identity stores and uses old broker routes. A transport called IRX is therefore not already the agreed v2 backend implementation.

## Existing proof seams and gaps

`IrxJournal` is already shared among Mac/phone transport components. Mac composition declares its journal at [MobileHostIrxRuntime.swift:73](https://github.com/manaflow-ai/cmux/blob/72ce5e9b41a83d3f8f3a21288856449f3580686e/Sources/Mobile/MobileHostIrxRuntime.swift#L73); iOS declares its journal at [MobileIrxRuntimeComposition.swift:89](https://github.com/manaflow-ai/cmux/blob/72ce5e9b41a83d3f8f3a21288856449f3580686e/ios/cmuxPackage/Sources/cmuxFeature/MobileIrxRuntimeComposition.swift#L89). Reuse the observable event path, but add the v2 environment/team/operation/session identity required by the acceptance document and scrub exceptions. A local journal does not prove deployed Axiom/Sentry coverage.

The existing [soak harness](https://github.com/manaflow-ai/cmux/blob/72ce5e9b41a83d3f8f3a21288856449f3580686e/scripts/irx-soak.py#L1) measures legacy admission elapsed time, five-minute relay rotations and input/output activity. Its fifteen-minute defaults and three-second admission threshold do not meet the new goal. It also types through a helper that must be reconciled with the current isolated GUI verification rules. The [release gate runner](https://github.com/manaflow-ai/cmux/blob/72ce5e9b41a83d3f8f3a21288856449f3580686e/ios/cmuxPackage/Sources/CmuxIrohReleaseGateSupport/MobileIrohReleaseGateRunner.swift#L341) already has sign-in, connected, workspace mutation and terminal readiness observations. Adapt these observations instead of declaring launch complete at socket admission.

Before deleting the older packages, trace imports: IRX still depends on their identity/grant models, low-level stream adapters and auth/retry helpers. Move genuinely shared primitives to the correct shared domain and delete obsolete behavior after callers switch. Broad deletion based only on a filename risks deleting useful stream code; leaving the old runtime reachable violates the requested replacement.

Integration order: finalize generated wire contracts and scoped persistence; install one shared v2 control/HTTP client; replace Mac/iOS composition and identity donation; retain peer/endpoint/stream owners behind v2 authority; replace presence/registry UI wiring; remove old routes/switches/listeners/models; then measure the deployed full stack. Every step must preserve new-scope trust and cancellation invariants.

Dictionary: A composition root connects concrete services at app startup. An admission authorizes a peer before application traffic. A generation distinguishes one owned lifecycle from an obsolete one. A stream lane carries one class of traffic inside a peer connection.
