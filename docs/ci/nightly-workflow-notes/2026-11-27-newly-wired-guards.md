# Newly wired guard merge verification

PR #58134 adds executable guard steps relative to base
`f00dca18a8e2c54e695c0b7eb7e58fbd743248db`. A previously failing test becomes this PR's own red when the PR first wires it.
Registry validation alone does not execute these tests. Run the exact workflow
steps below on the proposed merge head; retain the head SHA, terminal exit and
results file with the PR's verification evidence. The command derives added steps from that base rather than maintaining a second list. Every added step must pass.
Check that every named step appears in the results; `--keep-going` reaches later guards
after a failure. The deadline produces an incomplete, failing receipt.

```bash
python3 - <<'CHECK'
import json
import subprocess
from pathlib import Path
import yaml

base = "f00dca18a8e2c54e695c0b7eb7e58fbd743248db"
workflow = ".github/workflows/ci-guards.yml"
receipt = Path("/tmp/58134-newly-wired-guards.json")

def steps(doc):
    return {(job, step["name"]) for job, data in doc["jobs"].items()
            for step in data.get("steps", []) if "run" in step}

before = yaml.safe_load(subprocess.check_output(["git", "show", base + ":" + workflow]))
after = yaml.safe_load(Path(workflow).read_text())
expected = sorted({name for job, name in steps(after) - steps(before)})
assert expected, "No newly wired guards selected"
command = ["python3", "scripts/ci/run_ci_guards.py", "--all", "--keep-going",
           "--no-stamp", "--deadline", "900", "--results", str(receipt)]
for name in expected:
    command.extend(["--step", name])
run = subprocess.run(command)
results = json.loads(receipt.read_text())
missing = [name for name in expected if results.get(name) is not True]
assert not missing, f"Newly wired guards did not pass: {missing}"
assert run.returncode == 0, f"Guard runner exited {run.returncode}"
subprocess.run(["python3", "scripts/ci/guards_new_reds.py", "--tip", str(receipt)], check=True)
print(f"All {len(expected)} newly wired guards have passing results")
CHECK
```

`remote-web-wasm` condition may run after its router fails. Its mutation tests
reject broader exceptions and operand-valued fallback mistakes.
