# Owned-Mac SwiftPM fetches send the job token (2026-11-26)

Where: every "Keep Swift package builds on this owned Mac" step (`GH_TOKEN: ${{ github.token }}`, then
`scripts/ci/github_fetch_auth.py`).

Why: from 11-26 GitHub answered every anonymous github.com fetch from the owned Macs' shared address with 403
(SwiftPM git clones of apple/swift-crypto and friends, release-zip downloads), while the same Mac's
authenticated fetch (actions/checkout with the job token) succeeded. The prefetch now downloads release assets
through the API with the token (anonymous fallback), and `github_fetch_auth.py` appends one per-repository
`http.<url>/.extraheader` per Package.resolved pin to `$GITHUB_ENV`, so later xcodebuild/swift steps fetch
authenticated. manaflow-ai/cmux is skipped: actions/checkout already sends its own header.
