Generated by `node tests/browser-parity/diff/run.mjs report` from the recorded
differential results in `tests/browser-parity/diff/results/`. Each case is one
task expressed in the cmux API, in Aside (`aside repl`) and in ChatGPT for
Chrome (its reference runtime driving Chrome), run live; its observable
outcomes (values, page state, error class, event order, `isTrusted`, timing
class) are compared into a verdict per reference. Verdicts are recomputed
from the results by `tests/browser-parity/unit/diff.test.mjs`, which fails on
any cmux-worse verdict, any cmux result that misses its case's expectation,
and any member without a same or better case.

## Why cmux is better

### Against Aside (52)

- `tabs.list-get`: cmux reports the failing check or the invalid argument (a specific error) where the reference fails generically or silently accepts it.
- `tabs.attach`: cmux reports the failing check or the invalid argument (a specific error) where the reference fails generically or silently accepts it.
- `tabs.open-errors`: cmux reports the failing check or the invalid argument (a specific error) where the reference fails generically or silently accepts it.
- `print.display-console`: the REPL prints the last expression's value; Aside prints only what console.log writes.
- `page.goto.basic`: goto resolves with the HTTP response (status, ok); Aside's goto returns none.
- `page.goto.wait-until`: cmux reports the failing check or the invalid argument (a specific error) where the reference fails generically or silently accepts it.
- `page.goto.timeout`: goto honors its timeout; Aside waits its own 30 s readiness limit.
- `page.reload`: reload resolves with the HTTP response; Aside's returns none.
- `page.url-title.push-state`: page.url() follows history.pushState; Aside's url() still reports the old URL.
- `page.content`: page.content() is the full serialized document with its doctype, as in Playwright; Aside's omits the doctype.
- `page.query.dollar`: $() of a missing element is null and an invalid selector fails, as in Playwright; Aside returns an object for both.
- `page.getters.page-level`: getByRole pierces open shadow roots like Playwright (the shadow DOM's Action button counts); Aside's does not.
- `page.getters.errors`: cmux reports the failing check or the invalid argument (a specific error) where the reference fails generically or silently accepts it.
