## Adding a protocol

Add an entry to `index.json`: its owner, spec, version (the file and text that state it) and its vectors.
A shared protocol lists a test in each language with the text (`reads`) that shows the test loads the
vectors; one that is not shared yet names its gap. `cargo test -p cmux-protocol-index` fails when a path,
a version or a test's read of the vectors drifts from the tree.
