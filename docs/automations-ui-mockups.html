cmux automations: where they live

Three options from docs/automations-platonic-ideal.md section 8. Default picked: A. Each option is shown light and dark.

A. One "Automations" row + page (default)

One fixed row, red badge only for failures and needs-you. Runs are history rows, not workspaces. News still arrives in Home.

B. Sidebar group, runs as child workspaces

Familiar, but the sidebar grows with every automation and run; successful runs auto-archive after 24 h.

C. Home only: cards in the Chief chat + a Scheduled tab

Least chrome. Create and failures happen in the chat; managing many automations happens in the Scheduled tab.
