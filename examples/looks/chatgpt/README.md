# Codex desktop features

Install the [complete look](whole/) to use the features together. Each folder also installs on its own. The complete version combines the styles, menu and shortcut bindings, and Session Info views into one profile. Independent packages that supply the same customization file follow the host's normal file precedence.

| Feature | What to try |
| --- | --- |
| [Sidebar](sidebar/) | Switch between Priority, Projects and Recents. |
| [Threads and tasks](threads-tasks/) | Start or reopen a conversation and follow its active plan. |
| [Archiving](archiving/) | Archive a chat or opt into folding finished chats. |
| [Composer](composer/) | Enter a multiline draft in the rounded composer. |
| [Add menu](plus-menu/) | Attach files and inspect the attachment strip. |
| [Model and reasoning](model-reasoning/) | Switch models and choose an available effort. |
| [Project and environment](project-environment/) | Choose a working folder or computer. |
| [Execution modes](execution-modes/) | Work locally, create a worktree, or select a cloud machine. |
| [Diff and review](diff-review/) | Review a turn’s changed files and send line comments. |
| [Open in editor](open-in-editor/) | Open a local thread’s checkout in an editor or Finder. |
| [Settings](settings/) | Open appearance, chat font, or keyboard preferences. |
| [Keyboard shortcuts](shortcuts/) | Navigate, archive, switch models, and open review from the keyboard. |

The install commands in the feature guides target the NEXT branch. To try the open PR, use `@lane/chatgpt-desktop-looks` in place of `@feat-cmux-next`. For a local preview, use the file named in each guide. Run `python3 examples/looks/chatgpt/profiles.py` after editing a setup's companion files to refresh its portable preview.
