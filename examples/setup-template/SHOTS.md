# Gallery pictures

Every listed look shows the same states, so people can compare looks side by side. Take each from a
cmux window with this look installed, in a fresh demo profile so no private names show:
`cmux window screenshot --out screenshots/NAME.png`.

| File | State |
| --- | --- |
| `screenshots/chat.png` | An agent chat mid-conversation: a prompt, tool rows, a reply with a code block |
| `screenshots/chat-end.png` | The same chat scrolled to the end, with the composer |
| `screenshots/sidebar.png` | The sidebar with a few workspaces, one working, one needing input |
| `screenshots/stylesheet-over-a-light-theme.png` | `agent-pane/theme.css` over the other base theme |
