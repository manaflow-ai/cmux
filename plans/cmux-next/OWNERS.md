# cmux-next owners: who owns which area, and what to read first

Dozens of agents push straight to feat-cmux-next with no review. When two agents change one area
without talking, they undo each other (233 sidebar commits in four days; the indent changed four
times, [sidebar-owner.md](sidebar-owner.md)). Before you change an area below: read its doc, keep
its contract, and tell its owner what you changed (through the Performance Lead or Chief, or in
your report). The pre-push hook (`scripts/cmux-next/guardrails.py`) prints one warning line per
owned area a push touches. It never refuses. One row per area: a file belongs to the most specific
row that matches it (an exact path over a glob or a folder; a longer literal start wins), so the
daemon's crate rows never name a second owner for a file the holder row assigns. A crate no row lists has
no owner (see "Not listed" below); a new crate is not covered by any row until someone adds one.

Owners are agent names (a590), workstreams (PL-*, plans/cmux-next/perf-lead.md section 4) or
people. When a workstream ends, its row goes back to the Performance Lead. Change a row in the
same commit that changes ownership, and name who decided it.

A row's holder is whoever is live now, not the name written here: at push time the hook
(`scripts/cmux-next/owner_live.py`) resolves the cell to a live acpmux session, in order: one tagged
`owns=` the row's workstream (take one with `acpmux session tag SESSION owns=PL-acpmux`; a comma
list holds several), a live lane the row's role names (`lanes tabs-*,tab-strip*`: comma-separated fnmatch globs on
the lane's short name, the most recently active one), the session the cell names, that session's successor (`succeeds=`,
`failover=`), the Performance Lead (`owns=PL-lead`), then the coordinator. The owner line names that
session and the hook sends it the push (a stand-in lead or coordinator hears once a day per area and
is asked to give it a holder). Before 2026-11-22 a push into the acpmux crate named "PL-acpmux
(session cmux-4f)" for a month after cmux-4f had ended, and reached no one (cmux#50549). A role outlives the lanes that fill it, so prefer `lanes ...` to a session id: on
2026-11-23 seven rows still named ended sessions (a590, cmux-4f, cmux-1c, cmux-b6).
