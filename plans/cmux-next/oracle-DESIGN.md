## Linux tier results (p15-oracle-151)

`scripts/cmux-next/linux/tier-report.py` writes the section between the markers below.
It reads only the receipts of `swift-tier.sh --receipt` and `swift-shared.sh --receipt`
(p15-oracle-004): targets built, tests executed, build and incremental times. It does not
count from logs or source. It is a report, not a gate: an unmet done check does not change
its exit status. The done-check rows use the newest receipt without a sanitizer for each
runner. Sanitizer runs show in the progress table only.

To refresh it on the VM after a run:

```bash
bash scripts/cmux-next/linux/swift-tier.sh --all --receipt /tmp/oracle/linux-tier.json
bash scripts/cmux-next/linux/swift-shared.sh --receipt /tmp/oracle/linux-shared.json
python3 -I scripts/cmux-next/linux/tier-report.py --write-doc plans/cmux-next/oracle-DESIGN.md
```

To read one number from a receipt yourself, use the receipt path and sha256 that
the report gives, for example
`jq '[.units[] | select(.kind == "source" and .status == "built")] | length' /tmp/oracle/linux-tier.json`
or `jq '[.units[].tests.executed // 0] | add' /tmp/oracle/linux-tier.json`.
