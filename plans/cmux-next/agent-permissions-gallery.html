Computer use onboarding (one question per step)

What computer use does
Agents can use apps on this Mac for you: click, type, read the screen. You see a gray cursor with the agent’s name whenever one acts. Nothing runs until you allow it.
Accessibility
Lets the agent click and type in other apps.

Try it

How to stop
Press Esc twice, or click Stop on the cursor tag. Turn computer use off in Settings › Computer Use. Remove the grants in System Settings at any time.
