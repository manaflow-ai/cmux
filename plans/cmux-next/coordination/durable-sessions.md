## Landed
- 2026-10-03 (this push) cmux-tui + cmux-next R41: no false "Process exited". Daemon: a surfaceless terminal tab is dead only when its terminal ended (pending adopting|unadoptable, keyed by public term_ id); adoption completion pushes tree-changed; an unreadable host record (newer record_version after a rollback) keeps the terminal unadoptable instead of ending it, a watcher ends it with the host's exit sidecar, close ends the host only with nonce proof. Capability `terminal-state-v1`: tab JSON `terminal_state` (running|adopting|reconnecting|failed|unadoptable|exited), `host_record_version`, `end` (exited|signaled|host_lost{reason}|launch_failed). App: TerminalAttachMachine `processRevived` re-attaches an exited view; TabSnapshot/TabModel `terminalState`, `end`, `hostRecordVersion` (for the tab.restart banner). Tests: false_exit.rs (3), previous-build upgrade adoption (runs with CMUX_TUI_PREVIOUS_BIN), host-recovery harness runs /bin/sh when shell integration is off (interrupted_public_creation was macOS-host flaky).
