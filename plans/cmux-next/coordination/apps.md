# Lane: apps

## Active streams

## Landed
Moved from the pre-split COORDINATION.md (it came back with a1675174086 through a merge); wording unchanged.
- 2026-10-03 (feat-cmux-next-apps-routing) apps-v1: apps-list records carry `commands: [{op, title, symbol?, keywords?}]` (catalog ops on the palette surface; `apps-run {app, op}` runs them); the default app set is every valid package in the shipped first-party directory (`CMUX_APPS_FIRST_PARTY_DIR`, which the Mac app sets to Contents/Resources/apps/first-party; else apps/first-party next to the daemon), `CMUX_APPS_DEFAULT` overrides it; provider family `coderouter` added (app platform lead, Rust lane)
- 2026-10-02 (feat-cmux-next-apps-routing, lands after #16872 and #17008) cmux-tui daemon protocol: app op routing (plans/cmux-next/app-op-routing.md). Local commands `apps-provider-register {families}` (fs, action, app.settings, power, feed, integration, team, app, coderouter; no takeover of a live provider's family: `apps.provider.taken`) and `apps-provider-result {request_id, ok, body}`; events `apps-provider-request {request_id, app, actor, origin, op, params, idempotency_key?, deadline_ms}` and `apps-provider-cancel {request_id, reason: timeout|revoked|host_exited}`. No provider or a provider disconnect: `provider.unavailable` at once (APP-R1). Routed params are capped at 64 KiB, 64 calls outstanding per provider (app platform lead, Rust lane)
- 2026-10-02 (#17008) app supervisor enforces js/ABI.md on the host: view-state ops (an explicit list: pane/tab/screen/workspace focus, terminal input focus and viewport scroll, pane zoom, browser activate/navigate) and every `action.run` need a live token minted for that app, spent once; `action.run` refuses actions whose agent-surface exemption (action-surfaces.json `mcp`) is credentials, endsApp, systemChange, liveInput, devOnly, unimplemented, paletteInternal or dragGesture (scope.missing), and unknown ids (operation.unsupported); the runtime's filtering stays a courtesy (app platform lead, Rust lane)
- 2026-10-02 (this change, after #16872) cmux-tui daemon protocol: `apps-run` takes `gesture` (a client token for a palette/keybinding invocation, origin user only); the supervisor answers it with one command token of its own per client token (2 s, revoked at `done`), delivered through the runtime's `__cmuxAppRunCommand` ctxJSON `{gesture}`; tokens are spent only by a view-state change, other calls run as origin user while one is live (ABI.md). The actor stamp moved to the identity lane (identity.md section 3) (app platform lead, Rust lane)
- 2026-10-02 (this PR) cmux-tui daemon protocol: capability `apps-v1` (advertised only when the `cmux-app-host` binary sits next to the daemon or CMUX_APP_HOST_BIN names it); local-only commands `apps-list`, `apps-set` (origin user for installed/grant/unsandbox; idempotency keys persisted in `apps.json` in the session state dir), `apps-mount` (`context.preview` runs an uninstalled app with no grants), `apps-unmount`, `apps-dispatch` (origin user mints the gesture token), `apps-run` (async reply), `apps-logs`; events `apps-changed {revision, transaction}`, `request-settled`, `apps-host`, `apps-scene {mount_id, ops, reset?}`, `apps-mount-failed`, `apps-log`. New crate cmux-app-host (rquickjs =0.14.0, workspace and default member) and module cmux-tui-core::apps (new files; server.rs gains the hook, slot, disconnect and capability lines). App calls go through the cmux.protocol/2 dispatcher; the protocol has no actor field yet, so actor app:<id> is enforced in the supervisor only (app platform lead, Rust lane)
