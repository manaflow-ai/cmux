Markdown viewer with an omnibar: 6 variants

Each one reuses the browser omnibar (same field, glass, focus ring and keyboard). The field shows the real path, not a URL, and turns into a path editor on focus (Cmd+L). Git state comes from the file's repo. Share gives a local live link today and a GitHub link when the file is pushed. Pick a number to change the default; #1 is the Chief's default.

#1Path omnibar + repo chipRecommended
Same omnibar as the browser. Leading chip = repo and branch with a git state dot. Path is ~-shortened, file name bold. One Share button opens the share menu.
