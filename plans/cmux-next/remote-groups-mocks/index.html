Remote groups: 3 sidebar layouts

A remote group is a host (Mac mini over Tailscale or SSH, Linux VM, cmux cloud). Everything inside it runs on that host, and groups nest inside it: host > project > branch, at most 3 levels. Sample data. Design: plans/cmux-next/remote-groups-DESIGN.md section 7.

A. Host header + nested groupsRecommended

Each host is its own section. The header shows a host glyph, a status dot and a short status. Groups indent 12 pt per level, with the group color bar.
