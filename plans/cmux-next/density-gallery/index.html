Settings › Appearance › Density — 3 designs

One density token set sizes rows, padding, corners, icons and text together. Compact stays exactly as today. Built-ins: Ultra-compact, Compact (default), Cozy, Comfortable, Spacious. Any density can be duplicated into a custom one (name, level, spacing, text size, exact tokens), saved in cmux.json, exported and imported. Every preview below is drawn from the same token math the app uses.

A · Tiles with an inline editor Recommended

Each density is a tile that shows a real sidebar row, a tab and caption text at its size, so you pick by looking, not by name. Custom densities sit beside the built-ins. Duplicate opens the editor right under the tiles with a large live preview. It reuses the background picker's tile pattern, so it reads as part of Settings.
