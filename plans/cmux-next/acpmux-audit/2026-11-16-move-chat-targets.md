# Move chat targets and deferred moves

`_acpmux/move_targets` reads one peer snapshot and the existing placement verdict when a chat or its menu opens. It does no SSH probing and adds no idle polling. The CLI remains the transfer owner; `--after-turn` uses one bounded daemon wait and rechecks the turn before mutation. The regression tests cover target filtering, turn races, and a real two-daemon history/queue/draft transfer. Hosted receipts belong to the Move chat to Auto and any added machine PR.
