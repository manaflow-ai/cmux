# Kin and folder pages

PR #42609 keeps parent, fork and folder relations in persistent trees published with the hot summary index. A page reads its requested table part; snapshot pages are explicit cold requests. Family continuation uses a bounded ancestor path and preorder traversal, and an unreachable cursor returns `cursor_gone`. Subscriptions refuse these page-only filters.

The release measurements compare the same answer and cursor depth with 20 and 11,000 unrelated rows. Parent and folder moves, and a parent gaining its 5,001st child, use the tree-height budget. Candidate counters and a 2,000-row continuation test detect repeated whole-family walks. The feature remains behind the existing list setting; no v1 caller changes.
