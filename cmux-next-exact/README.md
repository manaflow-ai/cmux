# cmux (Exact)

cmux mobile app built with [Exact](https://github.com/expo/exact): Slack-style tabs Home, DMs, Activity, Search, More on mock data.

- `bun exact.mjs android` builds and installs on an emulator (needs Exact checked out and set up).
- `bun exact.mjs test android` runs app.test.contract.
- `bun exact.mjs ios --run` needs a Mac.
