title: Setup stays done
category: fixed
action: onboarding.continueSetup | Continue Setup

After you finish or skip setup, Continue Setup reopens it at the step you left, and setup no longer comes back at every launch. Quitting during the first setup now counts like closing it: setup shows on the next two launches, then stops. Continue Setup brings an open setup window forward instead of starting it over. Release, Nightly and each development build keep their own setup state.
