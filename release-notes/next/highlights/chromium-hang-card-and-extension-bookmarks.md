title: Chromium tabs report a page that stops answering, and extensions see your bookmarks
category: fixed

When a page in a Chromium tab stops answering, the tab now shows the Page unresponsive card. Before, Chromium ignored the hang in cmux tabs. Wait gives the page more time, and Exit page ends it.

Extensions that use bookmarks now see your cmux bookmarks. A bookmark that an extension adds or removes also changes in cmux.
