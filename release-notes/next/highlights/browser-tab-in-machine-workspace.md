title: New Browser Tab works in a machine's workspace
category: fixed
action: openBrowser | Try it

In a workspace on an SSH or Cloud machine, New Browser Tab (Cmd-Shift-L) opens a tab with the address bar ready to type. A "This Mac" chip in the address bar shows that the tab runs on this Mac. Its menu has Open on <machine>, which says why the machine cannot run the tab yet and offers Retry and Open Locally Instead. If the machine is not connected, cmux says so instead of doing nothing.
