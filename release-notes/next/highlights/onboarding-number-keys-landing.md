title: Setup asks what Ctrl-1…9 select, and ends on a New Tab
category: added
action: onboarding.continueSetup | Continue Setup

Setup has a Number Keys screen: Ctrl-1…9 select tabs and Ctrl-Option-1…9 select Spaces, or the other way around. The choice goes into cmux.json, and Settings > Keyboard Shortcuts can change each key later. Skip and Done now both end on a New Tab page when the window shows Home or no window is open, and the first launch uses the workspace it just made instead of making a second one.
