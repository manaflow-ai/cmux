title: New Cloud Workspace shows each step until the terminal opens
category: fixed
action: newCloudWorkspace | Try it

New Cloud Workspace now opens in the window at once and shows where the machine is: requesting, creating the VM, starting the machine, connecting to cmux-tui, then ready, with the time since you clicked. The terminal opens by itself when the machine is ready. If a step fails, you see the reason with Retry, Copy Error and Dismiss. A connected machine now shows as running, not provisioning.
