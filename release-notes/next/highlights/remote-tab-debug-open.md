title: Open a remote browser tab in development builds

Development builds have an Open Remote Browser Tab palette command (and `debug.remote_browser` on the debug socket) that opens a browser tab whose page streams from a loopback cmux.rb/1 host such as cmux-remote-browser-testhost. Right-click menus open as native menus, Cmd-click opens a remote background tab, and the omnibar loads typed addresses in the remote page.
