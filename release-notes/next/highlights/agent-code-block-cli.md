title: Read a chat’s latest code block from the CLI
category: new
docs: https://github.com/manaflow-ai/cmux/blob/feat-cmux-next/plans/cmux-next/cli-gui-parity.md

Use `cmux agents chat read CHAT --last-code-block` to get the latest complete code block without copying to the clipboard. MCP offers the same option, with secrets masked.
