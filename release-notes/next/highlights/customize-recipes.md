title: Thirteen customize recipes to try in one click
category: new
docs: https://cmux.com/docs/next/settings

Run `cmux customize recipes --open` for thirteen ready-made changes: a compact sidebar, a new font, your pull requests in the sidebar, a tiling look, a true black look, and looks like the Codex app and the Claude Code desktop app. Press Run on one to preview it, then apply or discard it.
