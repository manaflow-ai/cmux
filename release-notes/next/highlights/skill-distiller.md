title: Save a task you keep doing as a skill
category: new
docs: https://cmux.com/docs/next/agents
gallery: agent-pane.skill-offer/compact

When agents in a project have done the same kind of task three times, the third chat offers it as a skill with the steps and commands already drafted from those chats. Save it as it is, edit it first, or choose Not now and it won't be offered again. A saved skill reaches every agent cmux starts.
