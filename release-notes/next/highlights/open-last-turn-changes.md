title: Command-J G opens the last turn's changes
category: new
docs: https://cmux.com/docs/next/keyboard-shortcuts

In an agent chat, press Command-J, then G, to open the diff of the last turn that edited files in a tab beside the chat. It's the same diff that turn's View changes button opens, without scrolling back to find the card. Open Last Turn's Changes in the command palette does the same.
