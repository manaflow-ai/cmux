title: Add your own coding agent
category: new
action: palette.addHarness | Try it

Run Add Harness… from the command palette or the File menu, or click + in the model picker. The Harnesses page lists the agents found on this Mac with their status, and signs them in or starts a chat in one click. Custom harness… starts a chat that walks you through describing your own agent in one file, checks it, and the agent shows up in the model picker. A harness file inside a project runs only after you trust the folder and confirm the exact command on an Enable harness sheet.
