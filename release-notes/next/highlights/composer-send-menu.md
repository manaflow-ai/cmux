title: Right-click Send to queue a prompt or send it to a side chat
category: new
docs: https://cmux.com/docs/next/agents
gallery: agent-pane.composer-send-menu/turn-running

Right-click or press and hold Send in a chat: Queue for later (⌘↩) waits for the running turn, and Send in side chat (⌥↩) forks the chat beside it and sends the prompt there.
