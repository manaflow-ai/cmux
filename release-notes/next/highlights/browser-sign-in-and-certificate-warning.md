title: Sign-in sheet and safer certificate warnings in WebKit tabs
category: improved
action: docs | plans/cmux-next/browser-parity.md

A site that asks for a user name and password shows a sign-in sheet on its tab, with an optional Remember password box (off by default; private windows never remember). An untrusted certificate shows a full-page warning with Back to Safety as the default; Proceed is behind Show Details.
