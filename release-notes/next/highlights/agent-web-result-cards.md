title: Web results show each site's icon, and a fetched page is a link card
category: improved
docs: https://cmux.com/docs/next/agents

A web search's Sources line shows each site's icon next to its name, and its list has one row per page with the icon, title and site. A fetched page is one card with its icon, title and site. Click either to open the page in a cmux tab.
